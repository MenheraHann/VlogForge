# 创意总监 + Sub-Agent 架构说明

> 最后更新：2026-02-25（v4 — TA 合入 DA + VA 链式图生图 + 精简至 4 Agent）

## 整体结构

- **对用户**：内容侧只有一个入口 —— **创意总监（DA）**，负责编排与输出
- **对系统**：存在两个**平行部门**——**创意侧**（创意总监 + 其下属 Sub-Agent）与 **HR**；HR 与创意总监平级，可管理**所有 Agent** 的提示词
- **输出**：由创意总监汇总、排序后，以**一条连贯的多模态流**（文字 + 图片 + 视频）呈现给用户

---

## 两大阶段

| 阶段 | 触发时机 | 涉及 Agent | 产出 |
|------|----------|-----------|------|
| **素材创建** | 用户添加物品/人物/场景时，或模式 B 由 DA 拆解后触发 | ADA（素材设计师） | 素材档案（存入素材库） |
| **视频生成** | 用户选择素材 + 点击生成时 | DA → VA → VGA → FFmpeg | 最终视频 (.mp4) |

## 角色列表（共 4 个 Agent）

| 角色 | 代号 | 阶段 | 职责 | 核心 API | 状态 |
|------|------|------|------|----------|------|
| **素材设计师** | ADA | 素材创建 | 通过 asset_type 切换模式，处理物品/人物/场景的分析与生图 | Gemini 文本 + Nano Banana | 待做 |
| **创意总监** | DA | 视频生成 | 需求拆解（模式B）+ 脚本生成 + 编排 VA/VGA/FFmpeg + 自检审核 | Gemini 文本 | D3 骨架 |
| **美术指导** | VA | 视频生成 | 链式图生图生成分镜，逐帧保持画面一致性 | Nano Banana (img2img) | 待做 |
| **剪辑师** | VGA | 视频生成 | 首尾帧生成视频片段 | Veo 3.1 | 待做 |

### 已移除/合并的角色

| 原角色 | 变更 | 原因 |
|--------|------|------|
| TA（脚本策划） | 合入 DA | DA 既编排又创作，成为真正的"创意总监"；减少一层调用 |
| QA（质控） | 移除 | DA 通过 self_check 自检替代；独立 QA 增加成本和延迟 |
| MA（音频师） | 移除 | Veo 3+ 自带语音生成（`generate_audio=True`） |
| PDA/CDA/SDA | 合并为 ADA | 三者工作流同构，合并后减少约 60% 重复代码 |

## 协作流程

### 素材创建流程

```
用户添加物品 ──→ ADA（物品模式）
                   │ Gemini 文本分析产品图+描述
                   │ → 生成产品档案
                   │ → Nano Banana 生成产品说明图
                   │ → 检查产品尺寸（大型物品拒绝）
                   └ → 产品档案卡片 ✅ 存入素材库

用户添加人物 ──→ ADA（人物模式）
                   │ Gemini 文本拓展完整人设描述
                   │ → Nano Banana 生成多套造型方案
                   └ → 用户选择确认 ✅ 存入素材库

用户添加场景 ──→ ADA（场景模式）
                   │ Gemini 文本丰富场景环境描述
                   │ → Nano Banana 生成多个场景方案
                   └ → 用户选择确认 ✅ 存入素材库
```

### 模式 B：快速生成

```
用户一句话需求 → DA（创意总监）
                   │ Gemini 文本拆解为 物品+人物+场景 需求
                   │ → 调用 ADA（物品模式）
                   │ → 调用 ADA（人物模式）
                   │ → 调用 ADA（场景模式）
                   └ → 用户确认页面 → 存入素材库
```

### 视频生成流程

```
用户选择素材（1物品 + 1人物 + 1场景）+ 参数
       │
       ▼
┌──────────────────┐
│   DA（创意总监）   │ ← 编排核心 + 脚本创作
│  读取素材档案      │
│  + 用户额外要求    │
│  → Gemini 生成脚本 │ → ScriptOutput JSON
│  → self_check 自检 │   低于阈值 → 带反馈重跑（最多 1 次）
└──────┬───────────┘
       │ ① 调用 VA（链式图生图）
       ▼
┌──────────────────┐
│   VA（美术指导）   │ → N+1 张分镜图 (.png)
│  帧1 = 素材图     │   逐帧 img2img 保持画面一致
│   + 帧1提示词     │
│  帧2 = 帧1        │
│   + 帧2提示词     │
│  → Nano Banana   │
└──────┬───────────┘
       │ ② 调用 VGA（可并行）
       ▼
┌──────────────────┐
│  VGA（剪辑师）    │ → N 段视频片段 (.mp4)
│  首帧+尾帧+描述   │   每段 4~8 秒，自带语音
│  → Veo 3.1      │
└──────┬───────────┘
       │ ③ FFmpeg 拼接
       ▼
┌──────────────────┐
│  FFmpeg 拼接      │ → 最终视频 (.mp4)
│  裁重复帧 + 串接  │   可直接下载
└──────────────────┘
```

## 说明

- **DA** 是唯一对用户的内容出口，同时负责脚本创作和全流程编排
- **ADA** 在素材创建阶段独立工作（手动定制），或由 DA 调度（快速生成模式 B）
- **VA** 使用链式图生图（img2img）确保分镜图画面一致性
- 视频生成阶段的调用顺序：DA(脚本) → VA(分镜) → VGA(视频) → FFmpeg(拼接)
- 素材创建后可反复复用，同一模特/场景可搭配不同产品生成多个视频
- 后续若增删角色，在此文档同步更新
