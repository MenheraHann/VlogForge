# 创意总监 + Sub-Agent 架构说明

> 最后更新：2026-02-25

## 整体结构

- **对用户**：内容侧只有一个入口 —— **创意总监（DA）**，负责编排与输出
- **对系统**：存在两个**平行部门**——**创意侧**（创意总监 + 其下属 Sub-Agent）与 **HR**；HR 与创意总监平级，可管理**所有 Agent** 的提示词
- **输出**：由创意总监汇总、排序后，以**一条连贯的多模态流**（文字 + 图片 + 视频）呈现给用户

---

## 角色列表

### 一级：平行部门

| 部门/角色          | 对应名称            | 职责                                                                        | 状态    |
| ------------------ | ------------------- | --------------------------------------------------------------------------- | ------- |
| **创意总监** | DA (Decision Agent) | 接收用户需求 → 拆解任务 → 调度 Sub-Agent → 汇总结果 → 输出              | D3 待做 |
| **HR**       | HR (HR Agent)       | 管理所有 Agent 的提示词（prompt），优化其表现。与创意侧平行，不参与内容生产 | MVP 后  |

---

### Sub-Agent（创意总监下属，按职能）

| 角色               | 对应名称              | 职责简述                                         | 产出形态 | 核心 API                    | 状态      |
| ------------------ | --------------------- | ------------------------------------------------ | -------- | --------------------------- | --------- |
| **脚本策划** | TA (Text Agent)       | 生成 vlog 脚本 + 分镜提示词 + 风格指南           | JSON     | Gemini `generate_content` | ✅ 已完成 |
| **美术指导** | VA (Visual Agent)     | 根据脚本/分镜提示词生成分镜图，支持产品图植入    | 图像     | Nano Banana                 | 待做      |
| **剪辑师**   | VGA (Video Gen Agent) | 用首尾帧功能生成视频片段                         | 视频     | Veo 3.1                     | 待做      |
| **质控**     | QA (Review Agent)     | 审核视频片段质量（画面瑕疵、一致性、脚本匹配度） | 文本     | Gemini 多模态               | 待做      |

> **MA（音频师）已移除**：Veo 3+ 自带语音/对话生成（`generate_audio=True`），不再需要单独的音频 Agent。

## 协作流程

```
用户提交 6 项输入
       │
       ▼
┌──────────────────┐
│   DA（创意总监）   │ ← 编排核心，唯一对用户出口
│  接收 → 拆任务    │
└──────┬───────────┘
       │ ① 调用 TA
       ▼
┌──────────────────┐
│   TA（脚本策划）   │ → ScriptOutput JSON
│  标题 + 风格指南   │   （标题、风格指南、N个分段）
│  + N段分镜脚本    │
└──────┬───────────┘
       │ ② 调用 VA（逐帧）
       ▼
┌──────────────────┐
│   VA（美术指导）   │ → N+1 张分镜图 (.png)
│  风格指南+提示词   │   产品帧融入用户上传的产品图
│  → Nano Banana   │
└──────┬───────────┘
       │ ③ 调用 VGA（可并行）
       ▼
┌──────────────────┐
│  VGA（剪辑师）    │ → N 段视频片段 (.mp4)
│  首帧+尾帧+描述   │   每段 4~8 秒，自带语音
│  → Veo 3.1      │
└──────┬───────────┘
       │ ④ 调用 QA
       ▼
┌──────────────────┐
│   QA（质控）      │ → 通过 / 不通过 + 问题描述
│  抽帧 → Gemini   │   不通过则退回 VGA 重新生成
│  多模态审核       │
└──────┬───────────┘
       │ ⑤ FFmpeg 拼接
       ▼
┌──────────────────┐
│  FFmpeg 拼接      │ → 最终视频 (.mp4)
│  裁重复帧 + 串接  │   可直接下载
└──────────────────┘
```

## 说明

- **DA** 是唯一对用户的内容出口，负责调度所有 Sub-Agent 并汇总输出
- **HR** 为 MVP 后的扩展功能，负责管理所有 Agent 的 system prompt，不参与内容生产
- Sub-Agent 的调用顺序为固定流水线：TA → VA → VGA → QA → FFmpeg
- 后续若增删角色，在此文档同步更新
