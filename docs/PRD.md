# VlogForge 产品需求文档（PRD）

> 最后更新：2026-02-26（v7 — 素材三图体系 + 卡片双状态 + 详情页 tag 编辑）

## 一句话描述

用户定制物品、人物、场景三大素材，AI 自动组合生成真人 vlog 风格的带货短视频。

---

## 用户是谁

小商家、个体卖家、电商运营，想要低成本快速产出带货视频，但不会拍摄剪辑。

---

## 核心概念：素材库

VlogForge 的核心是一个**素材库**，包含三类可复用素材：

| 素材类型         | 说明             | 举例                             |
| ---------------- | ---------------- | -------------------------------- |
| 📦**物品** | 需要带货的产品   | 氨基酸洗面奶、保湿面膜、口红     |
| 👤**人物** | 出镜的 vlog 模特 | 亚洲短发女生、欧美主妇、清冷御姐 |
| 🏠**场景** | 拍摄的环境       | 明亮浴室、ins 风卧室、简约厨房   |

用户通过两种方式往素材库中添加素材：

- **手动定制**：逐个创建物品/人物/场景，精细控制
- **快速生成**：一句话描述需求，DA 自动拆解并调用 ADA 创建三类素材，用户确认后存入

素材创建后可**反复复用**，比如同一个模特拍不同产品的视频。

## 用户体验流程

### 模式 A：手动定制

#### A1. 添加物品（智能问卷模式）

用户上传产品图片 + 简单描述后，ADA 启动**智能问卷收集流程**，逐步补全产品信息。

**ADA 的信息收集原则：**

ADA 不使用固定问卷模板。拿到产品图片和描述后，ADA 自主判断「要把这个产品说明白，还缺什么信息」，动态生成问题。

以下维度仅作为 ADA 的参考范围（不是必须全部覆盖，也不限于此列表）：

> 产品名称、产品类别、核心卖点、解决什么问题、使用人群、使用场景、使用方法、材质/品质细节、价格信息、优惠福利、售后保障、发货时间、信任背书、促单话术 ……

**卖点优先级机制（P0 / P1 / P2）：**

ADA 分析产品后，需要按优先级梳理该产品的特征与卖点，并据此决定问卷内容的重点：

| 优先级       | 含义                         | 收集策略                                                                 |
| ------------ | ---------------------------- | ------------------------------------------------------------------------ |
| **P0** | 核心卖点，视频必须重点展示的 | **优先收集**。如果 ADA 无法从图片/描述中自信推断，必须主动询问用户 |
| **P1** | 辅助卖点，有助于增强说服力   | AI 预填为主，用户可修改                                                  |
| **P2** | 锦上添花信息，非必须         | AI 预填，标记为可选                                                      |

- P0 信息是视频脚本的**灵魂**，DA 会围绕 P0 构建叙事核心
- 向用户提出的问题控制在 **5~10 个**，优先完成 P0 等级的信息收集
- 如果 ADA 不确定某个产品的 P0 卖点（比如不常见的品类），应优先问用户「你认为这个产品最大的卖点是什么」

**ADA 的判断逻辑：**

- 分析产品类型后，决定哪些信息对**这个具体产品**是必要的
- 对每个维度标注 P0/P1/P2 优先级，P0 优先收集
- 比如一本书不需要「使用方法」，但需要「作者/内容简介」
- 比如食品需要「保质期/口味」，但不需要「材质」
- ADA 可以自由增加参考范围之外的维度，只要有助于充分理解产品
- **每道题必须附带 A/B 两个候选答案**，让用户做选择而非开放式填写
- 目标是：收集到的信息足以让 DA 写出有说服力的带货脚本，且 P0 卖点清晰明确

**流程（逐题选择式问卷）：**

```
第 1 步：用户输入
  图片：product_1.jpg, product_2.jpg
  描述："氨基酸洗面奶，温和不紧绷"

第 2 步：ADA 初步分析
  ADA 根据图片 + 描述自动识别产品类型，判断哪些维度是该产品必须补全的。
  对每个需要确认/补充的维度，ADA 生成一道「选择题」：
  - 选项 A：AI 生成的候选答案（更偏营销/卖点角度）
  - 选项 B：AI 生成的另一个候选答案（不同表述或不同侧重）
  - 选项 C：「我来填写」— 用户手动输入自己的回答

  返回给前端一份「逐题问卷」，一次只显示一道题。

第 3 步：逐题作答（核心交互）
  前端每次只展示一道题，用户完成后才出现下一题。

  ┌──────────────────────────────────────────────┐
  │  第 1/8 题                                     │
  │                                                │
  │  你认为这款洗面奶最大的卖点是什么？             │
  │                                                │
  │  ┌─ A ────────────────────────────────────┐    │
  │  │ 氨基酸温和配方，洗后不紧绷不假滑        │    │
  │  └────────────────────────────────────────┘    │
  │  ┌─ B ────────────────────────────────────┐    │
  │  │ 深层清洁不伤肌肤屏障，敏感肌的福音      │    │
  │  └────────────────────────────────────────┘    │
  │  ┌─ C ────────────────────────────────────┐    │
  │  │ ✏️ 我来填写...                          │    │
  │  └────────────────────────────────────────┘    │
  │                                                │
  │  ━━━━━━━━━━━━━━━━━━━━━━ 进度 1/8              │
  └──────────────────────────────────────────────┘

  交互规则：
  - 用户点击 A 或 B → 直接采用该选项，切到下一题
  - 用户点击 C → 展开文本输入框，用户输入后点「确认」→ 原样记录，切到下一题
  - 进度条显示当前是第几题/共几题
  - 可选题（P2）显示「跳过」按钮

第 4 步：ADA 生成最终素材
  所有题目回答完毕 → ADA 汇总全部回答 → 统一优化用户自定义输入的措辞
  （保留原意，措辞更专业/更适合营销）→ 生成完整产品档案
  → Nano Banana 生成三张产品图：
     ① 缩略图（UI 展示用，方便用户在素材库中辨识）
     ② 三视图（正面/侧面/背面，供 DA/VA/VGA 理解产品外观）
     ③ 功能介绍图（展示使用方式/功能特点，供 DA/VA/VGA 编排分镜避免错误使用）
  → 素材卡片存入素材库（状态：已确认） ✅
```

**AI 双选项生成规则：**

ADA 为每道题生成 A/B 两个选项时，需遵循以下原则：

- A 和 B 必须是**有实质差异**的两个回答，不能只是换个说法
- 选项文案风格偏**口语化 + 营销化**，适合带货短视频的语境
- P0 级别的题目：两个选项从不同角度切入（如功效 vs 情感、成分 vs 体验）
- P1 级别的题目：两个选项提供不同的信息密度或侧重
- 每个选项控制在 1~2 句话，不要太长

**用户自定义输入的优化时机：**

用户选择「我来填写」时，前端**原样记录**用户输入，不做实时优化。等所有题目回答完毕后，ADA 在生成最终物品档案（confirm 阶段）时**统一优化**所有用户自定义输入的措辞：

- 优化必须**保留用户的原始意思**，只调整措辞和表述
- 优化方向：更口语化、更有感染力、更适合短视频旁白使用
- 如果用户的原始输入已经很好，可以只做微调甚至原样保留
- 优化后的内容直接写入 product_info，不再需要用户二次确认

**物品限制：** 只接受上半身可完整演示的小型产品（化妆品、书本、手机壳等）。如果用户上传的是大型物品（家具、电器、汽车等），系统会在第 2 步**明确拒绝**并提示原因。

#### A2. 添加人物

用户上传模特照片，或口述想要的模特形象。

```
输入（方式一 — 上传照片）：
  图片：model_ref.jpg
  描述："就按这个形象来"

输入（方式二 — 口述描述）：
  描述："20 多岁亚洲女生，短发，邻家感，日常穿搭"

处理过程（用户不可见）：
  Step 1: 素材设计师（人物模式）拓展完整人设
  Step 2: Nano Banana 生成多套造型方案（用户选择）
  Step 3: 用户选定造型后，Nano Banana 额外生成两张图：
     ① 头像（面部特写，用于 UI 素材卡片缩略图）
     ② 上半身三视图（正面/左侧/右侧，供 DA/VA/VGA 理解人物形象）

输出（用户看到）：
  ✅ 人设档案卡片：
     形象：20-25岁亚洲女性，短发及肩，杏眼，肤色自然偏白
     气质：邻家亲和，活泼自然
     穿搭：白色基础T恤 + 浅色牛仔裤 / 米色卫衣 + 休闲裤
     [造型方案 A]  [造型方案 B]  [造型方案 C]  ← 多个选择
```

用户选择一个喜欢的造型 → ADA 自动生成头像 + 上半身三视图 → 素材卡片存入素材库（状态：已确认）。

#### A3. 添加场景

用户上传参考图，或口述想要的场景。

```
输入（方式一 — 上传照片）：
  图片：bathroom_ref.jpg

输入（方式二 — 口述描述）：
  描述："明亮的浴室，白色系，有镜子"

处理过程（用户不可见）：
  素材设计师（场景模式）丰富场景描述 → 用 Nano Banana 生成多个场景方案

输出（用户看到）：
  ✅ 场景档案卡片：
     场景：现代简约浴室
     环境：白色大理石瓷砖，圆形背光镜，木质置物架
     光线：自然光从左侧窗户射入，柔和明亮
     氛围：干净清爽，ins 博主感
     [场景方案 A]  [场景方案 B]  [场景方案 C]  ← 多个选择
```

用户选择一个喜欢的场景 → 该场景图**同时作为 UI 缩略图和 Agent 参考图**（vlog 拍摄中摄像机固定不动，场景不会变化，一张图即可满足所有需求） → 素材卡片存入素材库（状态：已确认）。

### 模式 B：一句话快速开始

用户输入一句话描述需求 + 上传产品图，系统同样走**智能问卷收集流程**。

区别在于：一句话模式下 ADA 会从描述中自动拆解出物品 + 人物 + 场景信息，利用更多上下文生成更精准的 A/B 选项，减少用户需要手动输入的量。但逐题问卷流程不跳过——信息不足就问，确保素材质量。

```
用户输入："帮我拍一个亚洲女生在浴室推荐氨基酸洗面奶的 vlog"
用户上传：product_1.jpg

系统流程：
  1. ADA 从一句话中提取：物品=洗面奶，人物=亚洲女生，场景=浴室
  2. 物品 → 走智能问卷（AI 大量预填，用户确认/补充） → 创建物品素材
  3. 人物 → ADA 拓展人设 → 生成造型方案 → 用户选择 → 创建人物素材
  4. 场景 → ADA 丰富描述 → 生成场景方案 → 用户选择 → 创建场景素材
  5. 三类素材全部就绪 → 自动填入生成槽位 → 用户点击生成
```

### 生成视频

素材准备好之后（通过拖拽已有素材 或 临时上传），用户在生成区操作：

```
第 1 步：填充槽位
  - 物品槽位：拖入已有物品素材 / 临时上传图片+描述（走问卷）
  - 人物槽位：拖入已有人物素材 / 临时上传参考图（可选，不填则 AI 推断）
  - 场景槽位：拖入已有场景素材 / 临时上传参考图（可选，不填则 AI 推断）

第 2 步：视频参数
  目标平台：抖音 / 小红书 / YouTube
  视频时长：15s / 30s / 60s
  一句话描述（可选）："开场要搞笑一点" / "重点展示使用过程"

第 3 步：等待生成（实时进度）
  ✅ 脚本生成完成                    ← 几秒钟
     ├── 开场：对镜自拍打招呼
     ├── 分段1：展示产品外包装
     ├── 分段2：使用过程
     └── 结尾：总结推荐
  ⏳ 分镜图生成中 (4/6)              ← 约 1~2 分钟
  ⬜ 视频片段生成                     ← 约 3~5 分钟
  ⬜ 拼接输出

第 4 步：预览和下载
  播放最终视频 → 下载 MP4
```

## 示例：完整流程

### 用户操作

```
1. 添加物品 → 上传洗面奶照片 + "氨基酸洗面奶，温和不紧绷"
   → 逐题问卷 → ADA 生成产品档案 + 三张图（缩略图/三视图/功能介绍图） ✅

2. 添加人物 → "20多岁亚洲女生，短发，邻家感"

3. 添加场景 → "明亮浴室，白色系"
   → ADA 生成 3 个方案 → 用户选第 1 个（同时作为 UI 缩略图和 Agent 参考） ✅

4. 生成视频 → 选择：洗面奶 + 短发女生 + 白色浴室
   → 平台：抖音，时长：30秒
   → 额外要求："开场提一个洗脸后紧绷的痛点"
```

```

分段 1（开场）：
  旁白："姐妹们！你们洗完脸有没有那种紧绷到笑不出来的感觉？"
```

## 幕后：Agent 分工

### 素材创建阶段（用户定制时触发）

由**素材设计师（ADA）**处理，通过 `asset_type` 切换不同的 prompt 模板：

```
用户添加物品 → ADA（物品模式 — 逐题选择式问卷）
                  │ Step 1: Gemini 分析图片+描述 → 初步识别产品
                  │ Step 2: 判断哪些信息维度是该产品必要的
                  │ Step 3: 对每个维度生成一道选择题（问题 + A/B 两个候选答案）
                  │ Step 4: 返回题目列表给前端 → 逐题展示，用户选 A/B 或自定义
                  │          卡片进入「待确认」状态
                  │ Step 5: 全部回答完毕 → confirm 阶段统一优化用户自定义输入的措辞
                  │ Step 6: 生成完整产品档案
                  │ Step 7: Nano Banana → 生成三张图：
                  │          ① 缩略图（UI 展示）
                  │          ② 三视图（DA/VA/VGA 参考）
                  │          ③ 功能介绍图（DA/VA/VGA 参考）
                  └ 标记 questionnaire_status = completed，卡片进入「已确认」状态

用户添加人物 → ADA（人物模式）
                  │ Step 1: Gemini 文本拓展完整人设描述
                  │ Step 2: Nano Banana → 生成多套造型方案
                  │ Step 3: 用户选择造型 → 卡片进入「待确认」状态
                  │ Step 4: Nano Banana → 基于选中造型生成两张图：
                  │          ① 头像（面部特写，UI 展示）
                  │          ② 上半身三视图（DA/VA/VGA 参考）
                  └ 卡片进入「已确认」状态

用户添加场景 → ADA（场景模式）
                  │ Step 1: Gemini 文本丰富场景环境描述
                  │ Step 2: Nano Banana → 生成多个场景方案
                  │ Step 3: 用户选择场景 → 选中的场景图同时用于：
                  │          · UI 缩略图（用户辨识）
                  │          · Agent 参考图（DA/VA/VGA，因 vlog 镜头固定）
                  └ 卡片直接进入「已确认」状态
```

### 视频生成阶段（用户点击生成时触发）

```
用户选择素材 + 参数 → DA（创意总监）
                        │
                        │ ① DA 自身生成脚本
                        │    读取素材档案（物品+人物+场景）+ 用户额外要求
                        │    → Gemini 文本生成脚本 + 分镜提示词
                        │    → self_check 自检 → 不通过则重跑
                        │
                        ├→ VA（美术指导）
                        │    链式图生图生成分镜：
                        │    帧1 = 素材图（人物造型+场景+产品）+ 帧1提示词
                        │    帧2 = 帧1 + 帧2提示词
                        │    帧3 = 帧2 + 帧3提示词 ...
                        │    → Nano Banana img2img，逐帧保持画面一致性
                        │
                        ├→ VGA（剪辑师）
                        │    用 Veo 3.1 首尾帧功能生成视频片段
                        │
                        └→ FFmpeg 拼接 → 最终视频
```

> **QA（质控）已移除**：DA 通过 self_check 自检替代独立 QA 环节
> **MA（音频师）已移除**：Veo 3+ 自带语音生成（`generate_audio=True`）
> **PDA/CDA/SDA 已合并为 ADA**：三者工作流同构，合并为一个 Agent + 三套 prompt 模板

## 前端布局

### 素材图片体系（v7）

不同素材类型生成不同数量和用途的图片：

| 素材类型 | 图片名称     | 数量 | UI 用途           | Agent 用途                          |
| -------- | ------------ | ---- | ----------------- | ----------------------------------- |
| 物品     | 缩略图       | 1    | 素材卡片展示      | —                                   |
| 物品     | 三视图       | 1    | 详情页查看        | DA/VA/VGA 理解产品外观              |
| 物品     | 功能介绍图   | 1    | 详情页查看        | DA/VA/VGA 编排分镜，避免错误使用    |
| 人物     | 头像         | 1    | 素材卡片展示      | —                                   |
| 人物     | 上半身三视图 | 1    | 详情页查看        | DA/VA/VGA 理解人物形象              |
| 场景     | 场景图       | 1    | 素材卡片展示      | DA/VA/VGA 理解拍摄环境（镜头固定）  |

> **设计原理**：vlog 拍摄中摄像机固定不动，场景始终不变，因此场景只需一张图即可同时满足 UI 展示和 Agent 参考。物品和人物因视角变化需要多角度参考图。

### 主页：素材库 + 生成区（统一入口）

主页分为上下两个区域，一屏展示。**不区分"快速生成"和"手动生成"**，统一为一个生成入口。

**上半部分 — 素材库（三列并排）**

物品、人物、场景三个类别同时展示为三列，不使用标签页切换。每列包含：

- 列标题 + 素材计数
- "添加"按钮
- 已有素材卡片列表（垂直排列）
- 素材卡片**可拖拽**到下方生成区的对应槽位

用户可在任意一列中添加/删除素材，三列始终同时可见。

### 素材卡片（双状态）

每张素材卡片显示**缩略图 + 名称 + 状态标签**，卡片右侧显示当前状态。

**状态定义：**

| 状态         | 触发条件                                 | 卡片外观                         |
| ------------ | ---------------------------------------- | -------------------------------- |
| **待确认**   | 物品：问卷未完成；人物：造型已选但图未生成 | 状态标签「待确认」+ 黄色标记     |
| **已确认**   | 所有信息收集完毕 + 图片全部生成完成       | 状态标签「已确认」+ 绿色标记     |

**卡片按钮：**

```
待确认状态：
┌──────────────────────────┐
│  [缩略图]  氨基酸洗面奶   │
│            待确认 🟡      │
│  [ 编辑 ]  [ 删除 ]      │
└──────────────────────────┘
  - 编辑：继续之前未完成的问卷流程
  - 删除：从素材库中移除

已确认状态：
┌──────────────────────────┐
│  [缩略图]  氨基酸洗面奶   │
│            已确认 🟢      │
│  [ 详情 ]  [ 删除 ]      │
└──────────────────────────┘
  - 详情：进入素材详情页
  - 删除：从素材库中移除
```

**缩略图来源：**

- 物品：`thumbnail_image`（ADA 生成的产品缩略图）
- 人物：`avatar_image`（ADA 生成的面部头像）
- 场景：`selected_scene`（用户选中的场景图）

> 只有**已确认**状态的素材可以拖拽到生成区槽位。待确认素材需先完成编辑。

**下半部分 — 生成区**

统一的生成入口，支持两种填充方式：

1. **拖拽已有素材**：从上方素材库拖拽**已确认**素材卡片到对应槽位（物品/人物/场景）
2. **临时上传**：直接在槽位中上传图片 + 描述，走智能问卷流程创建临时素材

## 边界说明

### 做什么

- 素材库管理：创建/存储/复用物品、人物、场景
- 逐题选择式问卷：ADA 分析产品后智能生成选择题（每题 A/B 两个 AI 选项 + 用户自定义），逐题展示，用户自定义输入由 AI 优化措辞
- 拖拽组合：从素材库拖拽已有素材到生成槽位
- 临时上传：在生成槽位直接上传图片，走问卷流程创建临时素材
- 一句话描述：可选的自然语言输入，ADA 从中提取信息辅助预填
- 组合生成：选择素材 → DA 编排全链路自动生成带货视频
- 支持 3 个平台比例（抖音/小红书竖屏、YouTube 横屏）
- 支持 3 种时长（15s / 30s / 60s）

### 不做什么

- 不做视频编辑器（用户不能手动改画面）
- 不做多版本对比（一次生成一个版本）
- 不做字幕烧录（用户自己在平台加）
- 不做 BGM（Veo 生成的视频自带语音，不额外加音乐）
- 不支持大型物品（家具、电器、汽车等需要全身/户外场景的产品）
