# VlogForge 产品需求文档（PRD）

> 最后更新：2026-02-27（v13 — 人物造型单图审核流程）

## 一句话描述

用户定制物品、人物两大素材，AI 自动组合生成真人 vlog 风格的带货短视频。

---

## 用户是谁

小商家、个体卖家、电商运营，想要低成本快速产出带货视频，但不会拍摄剪辑。

---

## 核心概念：素材库

VlogForge 的核心是一个**素材库**，包含两类可复用素材：

| 素材类型         | 说明             | 举例                             |
| ---------------- | ---------------- | -------------------------------- |
| 📦**物品** | 需要带货的产品   | 氨基酸洗面奶、保湿面膜、口红     |
| 👤**人物** | 出镜模特 + 拍摄场景（一体化） | 亚洲短发女生·客厅沙发、清冷御姐·ins 风卧室 |

用户通过两种方式往素材库中添加素材：

- **手动定制**：逐个创建物品/人物，精细控制
- **快速生成**：一句话描述需求，DA 自动拆解并调用 ADA 创建两类素材，用户确认后存入

素材创建后可**反复复用**，比如同一个模特拍不同产品的视频。

> **v10 变更**：场景不再作为独立素材类型。人物素材中包含拍摄场景信息，生成的是「人在场景中的半身近景照」（手机拍摄真实 vlog 质感）。这张图一图多用：UI 缩略图 + 首帧参考 + 分镜参考。

## 用户体验流程

### 模式 A：手动定制

#### A1. 添加物品（智能问卷模式）

用户上传产品图片 + 简单描述后，ADA 启动**智能问卷收集流程**，逐步补全产品信息。

**ADA 的信息收集原则：**

ADA 不使用固定问卷模板。拿到产品图片和描述后，ADA 自主判断「要把这个产品说明白，还缺什么信息」，动态生成问题。

以下维度仅作为 ADA 的参考范围（不是必须全部覆盖，也不限于此列表）：

> 产品名称、产品类别、核心卖点、解决什么问题、使用人群、使用场景、使用方法、材质/品质细节、价格信息、优惠福利、售后保障、发货时间、信任背书、促单话术 ……

**卖点优先级机制（P0 / P1 / P2）：**

ADA 分析产品后，需要按优先级梳理该产品的特征与卖点，并据此决定问卷内容的重点：

| 优先级       | 含义                         | 收集策略                                                                 |
| ------------ | ---------------------------- | ------------------------------------------------------------------------ |
| **P0** | 核心卖点，视频必须重点展示的 | **优先收集**。如果 ADA 无法从图片/描述中自信推断，必须主动询问用户 |
| **P1** | 辅助卖点，有助于增强说服力   | AI 预填为主，用户可修改                                                  |
| **P2** | 锦上添花信息，非必须         | AI 预填，标记为可选                                                      |

- P0 信息是视频脚本的**灵魂**，DA 会围绕 P0 构建叙事核心
- 向用户提出的问题控制在 **5~10 个**，优先完成 P0 等级的信息收集
- 如果 ADA 不确定某个产品的 P0 卖点（比如不常见的品类），应优先问用户「你认为这个产品最大的卖点是什么」

**ADA 的判断逻辑：**

- 分析产品类型后，决定哪些信息对**这个具体产品**是必要的
- 对每个维度标注 P0/P1/P2 优先级，P0 优先收集
- 比如一本书不需要「使用方法」，但需要「作者/内容简介」
- 比如食品需要「保质期/口味」，但不需要「材质」
- ADA 可以自由增加参考范围之外的维度，只要有助于充分理解产品
- **每道题必须附带 A/B 两个候选答案**，让用户做选择而非开放式填写
- 目标是：收集到的信息足以让 DA 写出有说服力的带货脚本，且 P0 卖点清晰明确

**流程（逐题选择式问卷）：**

```
第 1 步：用户输入
  图片：product_1.jpg, product_2.jpg
  描述："氨基酸洗面奶，温和不紧绷"

第 2 步：ADA 初步分析
  ADA 根据图片 + 描述自动识别产品类型，判断哪些维度是该产品必须补全的。
  对每个需要确认/补充的维度，ADA 生成一道「选择题」：
  - 选项 A：AI 生成的候选答案（更偏营销/卖点角度）
  - 选项 B：AI 生成的另一个候选答案（不同表述或不同侧重）
  - 选项 C：「我来填写」— 用户手动输入自己的回答

  返回给前端一份「逐题问卷」，一次只显示一道题。

第 3 步：逐题作答（核心交互）
  前端每次只展示一道题，用户完成后才出现下一题。

  ┌──────────────────────────────────────────────┐
  │  第 1/8 题                                     │
  │                                                │
  │  你认为这款洗面奶最大的卖点是什么？             │
  │                                                │
  │  ┌─ A ────────────────────────────────────┐    │
  │  │ 氨基酸温和配方，洗后不紧绷不假滑        │    │
  │  └────────────────────────────────────────┘    │
  │  ┌─ B ────────────────────────────────────┐    │
  │  │ 深层清洁不伤肌肤屏障，敏感肌的福音      │    │
  │  └────────────────────────────────────────┘    │
  │  ┌─ C ────────────────────────────────────┐    │
  │  │ ✏️ 我来填写...                          │    │
  │  └────────────────────────────────────────┘    │
  │                                                │
  │  ━━━━━━━━━━━━━━━━━━━━━━ 进度 1/8              │
  └──────────────────────────────────────────────┘

  交互规则：
  - 用户点击 A 或 B → 直接采用该选项，切到下一题
  - 用户点击 C → 展开文本输入框，用户输入后点「确认」→ 原样记录，切到下一题
  - 进度条显示当前是第几题/共几题
  - 可选题（P2）显示「跳过」按钮

第 4 步：ADA 生成最终素材
  所有题目回答完毕 → ADA 汇总全部回答 → 统一优化用户自定义输入的措辞
  （保留原意，措辞更专业/更适合营销）→ 生成完整产品档案
  → 基于用户上传的原始产品图片，img2img 生成两张产品图：
     ① 缩略图（以原图为参考，生成白底居中的电商风产品图，用于 UI 展示）
     ② 三视图（以原图为参考，生成正面/侧面/背面三角度纯产品画面，供 DA/VA/VGA 理解产品外观）
  → 同时生成一段**产品使用说明**（usage_guide）：
     面向完全没接触过该产品的人，逐步描述操作方式（如"拧开瓶盖""挤出黄豆大小"），
     明确指出产品各部位名称（如"白色旋转盖""按压泵头"），供 DA/VA/VGA 正确编排使用动作
  → 素材卡片存入素材库（状态：已确认） ✅
```

**AI 双选项生成规则：**

ADA 为每道题生成 A/B 两个选项时，需遵循以下原则：

- A 和 B 必须是**有实质差异**的两个回答，不能只是换个说法
- 选项文案风格偏**口语化 + 营销化**，适合带货短视频的语境
- P0 级别的题目：两个选项从不同角度切入（如功效 vs 情感、成分 vs 体验）
- P1 级别的题目：两个选项提供不同的信息密度或侧重
- 每个选项控制在 1~2 句话，不要太长

**用户自定义输入的优化时机：**

用户选择「我来填写」时，前端**原样记录**用户输入，不做实时优化。等所有题目回答完毕后，ADA 在生成最终物品档案（confirm 阶段）时**统一优化**所有用户自定义输入的措辞：

- 优化必须**保留用户的原始意思**，只调整措辞和表述
- 优化方向：更口语化、更有感染力、更适合短视频旁白使用
- 如果用户的原始输入已经很好，可以只做微调甚至原样保留
- 优化后的内容直接写入 product_info，不再需要用户二次确认

**物品限制：** 只接受上半身可完整演示的小型产品（化妆品、书本、手机壳等）。如果用户上传的是大型物品（家具、电器、汽车等），系统会在第 2 步**明确拒绝**并提示原因。

#### A2. 添加人物

用户上传模特照片，或口述想要的模特形象。**人物描述中需包含拍摄场景信息**（如客厅、卧室、书房等）。如果用户没有提供场景信息，ADA 会自动补充一个合理场景（优先室内家居场景）。

  描述："就按这个形象来，在客厅拍"

输入（方式二 — 口述描述）：
  描述："20 多岁亚洲女生，短发，邻家感，日常穿搭，卧室场景"

输入（方式三 — 不提供场景）：
  描述："20 多岁亚洲女生，短发，邻家感"

                     客厅，背景是沙发、夜晚自然光、明亮的环境、手机拍摄的真实质感

     场景：客厅，背景是米色沙发，夜晚自然光
     [造型预览图（半身近景）]

  Step 3: 用户审核造型图，三种操作：

  ┌──────────────────────────────────────────────┐
  │  [造型预览图]                                  │
  │                                                │
  │  形象：20-25岁亚洲女性，短发及肩               │
  │  气质：邻家亲和，活泼自然                      │

  │                                                │
  │  ┌─ ✅ 确认 ──┐  ┌─ 🔄 重新生成 ──┐         │

### 模式 B：一句话快速开始

用户输入一句话描述需求 + 上传产品图，系统同样走**智能问卷收集流程**。

区别在于：一句话模式下 ADA 会从描述中自动拆解出物品 + 人物（含场景）信息，利用更多上下文生成更精准的 A/B 选项，减少用户需要手动输入的量。但逐题问卷流程不跳过——信息不足就问，确保素材质量。

```
用户输入："帮我拍一个亚洲女生在浴室推荐氨基酸洗面奶的 vlog"
用户上传：product_1.jpg

系统流程：
  1. ADA 从一句话中提取：物品=洗面奶，人物=亚洲女生+浴室场景
  2. 物品 → 走智能问卷（AI 大量预填，用户确认/补充） → 创建物品素材
  3. 人物 → ADA 拓展人设 + 场景 → 生成一张半身近景造型图 → 用户确认/重新生成/调整意见 → 创建人物素材
  4. 两类素材全部就绪 → 自动填入生成槽位 → 用户点击生成
```

### 生成视频

素材准备好之后（通过拖拽已有素材 或 临时上传），用户在生成区操作：

```
第 1 步：填充槽位
  - 物品槽位：拖入已有物品素材 / 临时上传图片+描述（走问卷）
  - 人物槽位：拖入已有人物素材 / 临时上传参考图（可选，不填则 AI 推断）

第 2 步：视频参数
  目标平台：抖音 / 小红书 / YouTube
  视频时长：15s / 30s / 60s
  一句话描述（可选）："开场要搞笑一点" / "重点展示使用过程"

第 3 步：等待生成（逐帧/逐段实时进度）
  ✅ 脚本生成完成                    ← 几秒钟
     ├── 开场：对镜自拍打招呼
     ├── 分段1：展示产品外包装
     ├── 分段2：使用过程
     └── 结尾：总结推荐
  ⏳ 分镜图生成中 (4/7)              ← 约 1~2 分钟
     每生成一帧立即推送前端显示缩略图 + 进度 (N/总数)
  ⏳ 视频片段生成中 (2/6)            ← 约 1~2 分钟（首尾帧并行）
     每段完成立即推送前端显示视频预览 + 进度 (N/总数)
  ⬜ 拼接输出

第 4 步：预览和下载
  播放最终视频 → 下载 MP4
```

## 渲染队列

### 功能概述

类似浏览器下载管理器的视频渲染队列，用户可随时提交多个视频生成任务，队列面板实时展示所有任务状态。用户不必等待当前视频生成完毕才能操作，提交后即可回到素材库继续工作。

### 用户故事

- 用户点击"生成视频"后，任务加入队列，可以立刻回去修改素材或创建新任务
- 用户在队列面板中查看所有任务的状态和进度
- 用户可以取消排队中或正在渲染的任务
- 已完成的任务可以直接预览/下载

### 队列规则

- **串行执行**：同一时间只运行一个渲染任务
- **FIFO 顺序**：先提交的先执行
- **自动接续**：取消当前任务后，队列中下一个自动开始
- **追加入队**：新任务始终加到队尾

### 任务状态

| 状态   | 英文      | 说明                         |
| ------ | --------- | ---------------------------- |
| 排队中 | queued    | 等待前面的任务完成           |
| 渲染中 | running   | 当前正在执行的任务           |
| 已完成 | completed | 生成成功，可预览/下载        |
| 已失败 | failed    | 生成失败，显示错误原因       |
| 已取消 | cancelled | 用户手动取消                 |

状态流转：

```
queued → running → completed
                 → failed
queued → cancelled（排队中取消）
running → cancelled（渲染中取消，停止当前生成）
```

**卡片信息：**

- 状态标签 + 对应颜色标记
- 进度条：仅渲染中任务显示
- 渲染中的任务展开显示详细阶段：脚本 → 分镜 → 视频 → 拼接
- 操作按钮：
  - 排队中 / 渲染中 → 取消
  - 已完成 → 预览 / 下载
  - 已失败 → 重试（重新加入队尾）

### API 设计

| 方法 | 端点 | 说明 |
| ---- | ---- | ---- |
| `GET` | `/api/jobs` | 获取所有任务列表（支持按状态筛选） |
| `POST` | `/api/jobs/{job_id}/cancel` | 取消指定任务 |
| `POST` | `/api/generate/v2` | 保持不变，返回 `job_id` 加入队列 |
| `GET` | `/api/status/{job_id}` | 保持不变，查询单个任务状态 |
| `GET` | `/api/stream/{job_id}` | 保持不变，SSE 实时进度推送 |

### 与现有功能的关系

- **生成区**：用户点击「开始生成」后，任务不再阻塞当前页面，而是加入渲染队列，页面自动跳回素材库
- **进度页**：原有的 SSE 实时进度机制（v11）复用为队列中单个任务的进度详情
- **素材库**：用户提交生成任务后可立即回到素材库，继续创建/编辑素材或提交新的生成任务

> **v12 新增**：渲染队列功能，支持多任务串行执行、实时状态追踪、任务取消与重试。用户无需等待当前视频生成完毕即可提交新任务。

## 幕后：Agent 分工

### 素材创建阶段（用户定制时触发）

由**素材设计师（ADA）**处理，通过 `asset_type` 切换不同的 prompt 模板：

```
用户添加物品 → ADA（物品模式 — 逐题选择式问卷）
                  │ Step 1: Gemini 分析图片+描述 → 初步识别产品
                  │ Step 2: 判断哪些信息维度是该产品必要的
                  │ Step 3: 对每个维度生成一道选择题（问题 + A/B 两个候选答案）
                  │ Step 4: 返回题目列表给前端 → 逐题展示，用户选 A/B 或自定义
                  │          卡片进入「待确认」状态
                  │ Step 5: 全部回答完毕 → confirm 阶段统一优化用户自定义输入的措辞
                  │ Step 6: 生成完整产品档案
                  │ Step 7: img2img（以用户原始产品图为参考）→ 生成两张图：
                  │          ① 缩略图（白底电商风，UI 展示）
                  │          ② 三视图（纯产品画面，正/侧/背三角度，DA/VA/VGA 参考）
                  │ Step 8: 生成产品使用说明（usage_guide）→ 逐步操作文字，供 DA/VA/VGA 参考
                  └ 标记 questionnaire_status = completed，卡片进入「已确认」状态

用户添加人物 → ADA（人物模式 — 含场景信息）
                  │ Step 1: Gemini 文本拓展完整人设 + 场景描述
                  │          （如果用户未提供场景，ADA 自动补充室内家居场景）
                  │ Step 2: Nano Banana → 生成一张造型图
                  │          「人在场景中的半身近景照」
                  │          提示词风格：半身近景、中国女性、25岁、长发、素颜、面对镜头、
                  │                     客厅，背景是沙发、夜晚自然光、手机拍摄的真实质感
                  │ Step 3: 用户审核造型图，三种操作：
                  │          · 确认 → 造型图一图多用（UI 缩略图 + 首帧参考 + 分镜参考）
                  │                   卡片进入「已确认」状态
                  │          · 重新生成 → 用原始提示词重新生成一张（替换旧图）→ 回到 Step 3
                  │          · 调整意见 → 用户输入修改建议，ADA 融入原始提示词重新生成
                  │                       （替换旧图）→ 回到 Step 3
                  └ 用户确认后卡片进入「已确认」状态
```

### 视频生成阶段（用户点击生成时触发）

```
用户选择素材 + 参数 → DA（创意总监）
                        │
                        │ ① DA 自身生成脚本
                        │    读取素材档案（物品+人物）+ 用户额外要求
                        │    → Gemini 文本生成脚本 + 分镜提示词
                        │    → 每段旁白严格控制在 3~4 秒（中文 30~45 字）
                        │    → voice_anchor 声音锚定（全英文）确保跨段声音一致
                        │    → self_check 自检 → 不通过则重跑
                        │
                        ├→ VA（美术指导）
                        │    链式图生图生成分镜（N+1 帧）：
                        │    帧1 = 人物场景图（portrait_image）+ 产品 + 帧1提示词
                        │    帧2 = 帧1 + 帧2提示词
                        │    帧3 = 帧2 + 帧3提示词 ...
                        │    → Nano Banana img2img，逐帧保持画面一致性
                        │
                        ├→ VGA（剪辑师） — v6 首尾帧并行 + 智能裁切
                        │    每段 = 首帧图 + 尾帧图 + voice_anchor + veo_description
                        │    → Veo 3.1 首尾帧模式（6s/段），所有片段可并行生成
                        │    → 智能裁切：提取尾部帧，MSE 对比目标尾帧，截断 AI 漂移
                        │    → 并发上限 3 段，速度比串行快 3~4 倍
                        │
                        └→ FFmpeg 拼接（裁掉相邻片段重复首帧）→ 最终视频
```

| 角色       | 代号 | 阶段     | 职责                                                     | 核心 API                  |
| ---------- | ---- | -------- | -------------------------------------------------------- | ------------------------- |

## 前端布局

### 素材图片与文字体系（v10）

不同素材类型生成不同的图片和文字：

| 素材类型 | 名称           | 类型 | UI 用途           | Agent 用途                          |
| -------- | -------------- | ---- | ----------------- | ----------------------------------- |
| 物品     | 缩略图         | 图片 | 素材卡片展示      | —（img2img 参考原图生成白底电商风） |
| 物品     | 三视图         | 图片 | 详情页查看        | DA/VA/VGA 理解产品外观（img2img 纯产品画面，无文字） |
| 物品     | 使用说明       | 文字 | 详情页查看        | DA/VA/VGA 正确编排产品使用动作（逐步操作描述） |
| 人物     | 半身近景图     | 图片 | 素材卡片展示      | DA/VA/VGA 首帧参考 + img2img 分镜参考（人在场景中） |

> **v10 设计原理**：人物素材生成「人在场景中的半身近景照」（手机拍摄真实 vlog 质感），一图多用：UI 缩略图 + 首帧参考 + 分镜参考。场景信息包含在人物素材中，不再独立存在。
> **物品图片生成方式**：两张图均使用 **img2img**（图生图），以用户上传的原始产品照片作为输入参考，确保生成图片严格还原真实产品外观。三视图为纯产品画面（无文字叠加）。
> **使用说明（usage_guide）**：一段详细的逐步操作文字，面向「完全没接触过该产品的人」，清晰描述每一步操作（如"拧开白色旋转瓶盖"），并指明产品各部位名称（如"按压泵头""瓶口"），让 DA/VA/VGA 能正确编排产品使用动作，避免画面错误。

### 主页：素材库 + 生成区（统一入口）

主页分为上下两个区域，一屏展示。**不区分"快速生成"和"手动生成"**，统一为一个生成入口。

**上半部分 — 素材库（两列并排）**

物品、人物两个类别同时展示为两列，不使用标签页切换。每列包含：

- 列标题 + 素材计数
- "添加"按钮
- 已有素材卡片列表（垂直排列）
- 素材卡片**可拖拽**到下方生成区的对应槽位

用户可在任意一列中添加/删除素材，两列始终同时可见。

### 素材卡片（三状态）

每张素材卡片显示**缩略图 + 名称 + 状态标签**，卡片右侧显示当前状态。

**状态定义：**

| 状态         | 触发条件                                 | 卡片外观                         |
| ------------ | ---------------------------------------- | -------------------------------- |
| **生成中**   | ADA 正在生成素材（图片渲染/文本分析中）   | 骨架占位卡片 + 呼吸动画 + 蓝色标记 |
| **待确认**   | 物品：问卷未完成；人物：造型未确认 | 状态标签「待确认」+ 黄色标记     |
| **已确认**   | 所有信息收集完毕 + 图片全部生成完成       | 状态标签「已确认」+ 绿色标记     |

**生成中占位卡片（v11 新增）：**

用户提交创建请求（物品确认/人物创建）后，素材库中**立即**出现一张占位卡片，告知用户后台正在工作。避免用户看到空白或以为请求丢失。

## 视频生成技术参数（v8）

### 分段时长与数量

| 目标时长 | 分段数 | 分镜帧数 | 实际时长（裁切后） |
| -------- | ------ | -------- | ------------------ |
| 15s      | 3 段   | 4 帧     | ~16.5s             |
| 30s      | 6 段   | 7 帧     | ~33s               |
| 60s      | 11 段  | 12 帧    | ~60.5s             |

- 每段视频 **6 秒**，经智能裁切后约 **5~5.5 秒**
- 每段旁白 **3~4 秒**（中文 30~45 字），剩余 2 秒为视觉过渡

### VGA 首尾帧并行 + 智能裁切

**生成模式：** 每段视频独立使用首帧 + 尾帧 + 文字描述生成（Veo 3.1 `generate_video_segment`），所有段可并行。

**智能裁切（解决尾帧漂移）：**

Veo 首尾帧模式中，目标尾帧可能在 ~5s 就出现，之后 ~1s 是 AI 自由发挥（漂移）。智能裁切在视频尾部搜索最接近目标尾帧的帧，在该时间点截断。

```
视频 (6s):
0s ──── 1s ──── 2s ──── 3s ──── 4s ──── 5s ── 6s
[首帧]  [─── 旁白 3~4s ───]  [视觉过渡]  [漂移]
                                ↑ 尾帧到达 ↑ 裁切点
```

算法：
1. FFmpeg 提取视频最后 3 秒的帧（12fps 采样）
2. 每帧缩放到 256×256 灰度，与目标尾帧计算 MSE（均方误差）
3. 取 MSE 最低的帧为最佳匹配，在该时间点 +0.04s 截断
4. 如果最佳帧在视频最后 0.2s 内，则不裁切

**声音一致性：** 每段 prompt 前缀加 `voice_anchor`（DA 生成的全英文声音特征描述），引导 Veo 跨段保持同一声线。

**并行参数：** 最大并发 3 段，避免 API 限流。

## 边界说明

### 做什么

- 素材库管理：创建/存储/复用物品、人物
- 逐题选择式问卷：ADA 分析产品后智能生成选择题（每题 A/B 两个 AI 选项 + 用户自定义），逐题展示，用户自定义输入由 AI 优化措辞
- 拖拽组合：从素材库拖拽已有素材到生成槽位
- 临时上传：在生成槽位直接上传图片，走问卷流程创建临时素材
- 一句话描述：可选的自然语言输入，ADA 从中提取信息辅助预填
- 组合生成：选择素材 → DA 编排全链路自动生成带货视频
- 渲染队列：多任务串行排队、实时状态追踪、取消/重试、完成后预览下载
- 支持 3 个平台比例（抖音/小红书竖屏、YouTube 横屏）
- 支持 3 种时长（15s / 30s / 60s）

### 不做什么

- 不做视频编辑器（用户不能手动改画面）
- 不做多版本对比（一次生成一个版本，但可通过队列依次生成多个任务）
- 不做字幕烧录（用户自己在平台加）
- 不做 BGM（Veo 生成的视频自带语音，不额外加音乐）
- 不支持大型物品（家具、电器、汽车等需要全身/户外场景的产品）
