# VlogForge 产品需求文档（PRD）

> 最后更新：2026-02-25（v4 — TA 合入 DA + VA 链式图生图 + 精简至 4 Agent）

## 一句话描述

用户定制物品、人物、场景三大素材，AI 自动组合生成真人 vlog 风格的带货短视频。

---

## 用户是谁

小商家、个体卖家、电商运营，想要低成本快速产出带货视频，但不会拍摄剪辑。

---

## 核心概念：素材库

VlogForge 的核心是一个**素材库**，包含三类可复用素材：

| 素材类型 | 说明 | 举例 |
|----------|------|------|
| 📦 **物品** | 需要带货的产品 | 氨基酸洗面奶、保湿面膜、口红 |
| 👤 **人物** | 出镜的 vlog 模特 | 亚洲短发女生、欧美主妇、清冷御姐 |
| 🏠 **场景** | 拍摄的环境 | 明亮浴室、ins 风卧室、简约厨房 |

用户通过两种方式往素材库中添加素材：
- **手动定制**：逐个创建物品/人物/场景，精细控制
- **快速生成**：一句话描述需求，DA 自动拆解并调用 ADA 创建三类素材，用户确认后存入

素材创建后可**反复复用**，比如同一个模特拍不同产品的视频。

---

## 用户体验流程

### 模式 A：手动定制

#### A1. 添加物品

用户上传 1~3 张产品实物图，附带一句话描述产品是什么、怎么用。

```
输入：
  图片：product_1.jpg, product_2.jpg
  描述："氨基酸洗面奶，挤出泡沫涂在脸上打圈按摩，清水冲洗，温和不紧绷"

处理过程（用户不可见）：
  素材设计师（物品模式）分析产品 → 生成产品档案 → 用 Nano Banana 生成产品说明图

输出（用户看到）：
  ✅ 产品档案卡片：
     名称：氨基酸洗面奶
     类型：面部护肤
     使用方式：挤压 → 打泡 → 上脸按摩 → 冲洗
     核心卖点：氨基酸温和配方，洗后不紧绷
     [产品说明图]  ← 一张图文并茂的产品功能图
```

**物品限制：** 只接受上半身可完整演示的小型产品（化妆品、书本、手机壳等）。如果用户上传的是大型物品（家具、电器、汽车等），系统会**明确拒绝**并提示原因。

#### A2. 添加人物

用户上传模特照片，或口述想要的模特形象。

```
输入（方式一 — 上传照片）：
  图片：model_ref.jpg
  描述："就按这个形象来"

输入（方式二 — 口述描述）：
  描述："20 多岁亚洲女生，短发，邻家感，日常穿搭"

处理过程（用户不可见）：
  素材设计师（人物模式）拓展完整人设 → 用 Nano Banana 生成多套造型方案

输出（用户看到）：
  ✅ 人设档案卡片：
     形象：20-25岁亚洲女性，短发及肩，杏眼，肤色自然偏白
     气质：邻家亲和，活泼自然
     穿搭：白色基础T恤 + 浅色牛仔裤 / 米色卫衣 + 休闲裤
     [造型方案 A]  [造型方案 B]  [造型方案 C]  ← 多个选择
```

用户选择一个喜欢的造型，确认后存入素材库。

#### A3. 添加场景

用户上传参考图，或口述想要的场景。

```
输入（方式一 — 上传照片）：
  图片：bathroom_ref.jpg

输入（方式二 — 口述描述）：
  描述："明亮的浴室，白色系，有镜子"

处理过程（用户不可见）：
  素材设计师（场景模式）丰富场景描述 → 用 Nano Banana 生成多个场景方案

输出（用户看到）：
  ✅ 场景档案卡片：
     场景：现代简约浴室
     环境：白色大理石瓷砖，圆形背光镜，木质置物架
     光线：自然光从左侧窗户射入，柔和明亮
     氛围：干净清爽，ins 博主感
     [场景方案 A]  [场景方案 B]  [场景方案 C]  ← 多个选择
```

用户选择一个喜欢的场景，确认后存入素材库。

---

### 模式 B：快速生成（一句话模式）

用户输入一句话描述需求，**DA（创意总监）**自动拆解为物品 + 人物 + 场景，然后调用 ADA 创建各类素材：

```
用户输入："帮我拍一个亚洲女生在浴室推荐氨基酸洗面奶的 vlog"

DA 拆解需求 → 调用 ADA 创建素材 → 用户确认页面：
  📦 物品：氨基酸洗面奶（需要你上传产品图）
  👤 人物：20多岁亚洲女生，自然亲和  [AI 已生成造型]
  🏠 场景：明亮浴室，白色系           [AI 已生成场景图]

用户确认 / 修改 → 素材全部存入素材库 → 进入视频生成
```

---

### 组合生成视频

无论哪种模式，素材准备好之后，用户进入**视频生成**：

```
第 1 步：选择素材
  从素材库中选择：1 个物品 + 1 个人物 + 1 个场景

第 2 步：视频参数
  目标平台：抖音 / 小红书 / YouTube
  视频时长：15s / 30s / 60s
  额外要求（可选）："开场要搞笑一点" / "重点展示使用过程"

第 3 步：等待生成（实时进度）
  ✅ 脚本生成完成                    ← 几秒钟
     ├── 开场：对镜自拍打招呼
     ├── 分段1：展示产品外包装
     ├── 分段2：使用过程
     └── 结尾：总结推荐
  ⏳ 分镜图生成中 (4/6)              ← 约 1~2 分钟
  ⬜ 视频片段生成                     ← 约 3~5 分钟
  ⬜ 拼接输出

第 4 步：预览和下载
  播放最终视频 → 下载 MP4
```

## 示例：完整流程

### 用户操作

```
1. 添加物品 → 上传洗面奶照片 + "氨基酸洗面奶，温和不紧绷"
   → ADA（物品模式）生成产品说明图 ✅

2. 添加人物 → "20多岁亚洲女生，短发，邻家感"
   → ADA（人物模式）生成 3 套造型 → 用户选第 2 套 ✅

3. 添加场景 → "明亮浴室，白色系"
   → ADA（场景模式）生成 3 个方案 → 用户选第 1 个 ✅

4. 生成视频 → 选择：洗面奶 + 短发女生 + 白色浴室
   → 平台：抖音，时长：30秒
   → 额外要求："开场提一个洗脸后紧绷的痛点"
```

### DA 生成的脚本（DA 读取素材档案 + 用户要求后生成）

```
标题：「洗完脸不紧绷是什么体验？」

分段 1（开场）：
  旁白："姐妹们！你们洗完脸有没有那种紧绷到笑不出来的感觉？"
  画面：女生（短发邻家造型）在浴室（白色系）对镜头说话

分段 2（展示产品）：
  旁白："这款氨基酸洗面奶，成分超温和"
  画面：手持洗面奶（产品植入）特写

分段 3（使用过程）：
  旁白："泡沫很绵密，上脸打圈完全不刺激"
  画面：涂泡沫在脸上

分段 4（效果展示）：
  旁白："你看，洗完完全不紧绷，皮肤滑滑的"
  画面：擦干脸，展示皮肤

分段 5（收尾）：
  旁白："真的推荐你们试试，链接放评论区了！"
  画面：对镜头比心 + 产品摆拍
```

### 最终输出

30 秒 MP4 视频，竖屏 9:16，带真人画面 + 语音旁白，可直接发抖音。

## 幕后：Agent 分工

### 素材创建阶段（用户定制时触发）

由**素材设计师（ADA）**处理，通过 `asset_type` 切换不同的 prompt 模板：

```
用户添加物品 → ADA（物品模式）
                  │ Gemini 文本分析产品图+描述 → 生成产品档案
                  │ Nano Banana → 生成产品说明图
                  └ 检查是否为小型产品，大型物品拒绝

用户添加人物 → ADA（人物模式）
                  │ Gemini 文本拓展完整人设描述
                  │ Nano Banana → 生成多套造型方案
                  └ 用户选择确认

用户添加场景 → ADA（场景模式）
                  │ Gemini 文本丰富场景环境描述
                  │ Nano Banana → 生成多个场景方案
                  └ 用户选择确认
```

### 视频生成阶段（用户点击生成时触发）

```
用户选择素材 + 参数 → DA（创意总监）
                        │
                        │ ① DA 自身生成脚本
                        │    读取素材档案（物品+人物+场景）+ 用户额外要求
                        │    → Gemini 文本生成脚本 + 分镜提示词
                        │    → self_check 自检 → 不通过则重跑
                        │
                        ├→ VA（美术指导）
                        │    链式图生图生成分镜：
                        │    帧1 = 素材图（人物造型+场景+产品）+ 帧1提示词
                        │    帧2 = 帧1 + 帧2提示词
                        │    帧3 = 帧2 + 帧3提示词 ...
                        │    → Nano Banana img2img，逐帧保持画面一致性
                        │
                        ├→ VGA（剪辑师）
                        │    用 Veo 3.1 首尾帧功能生成视频片段
                        │
                        └→ FFmpeg 拼接 → 最终视频
```

### 完整角色列表

| 角色 | 代号 | 阶段 | 职责 | 核心 API |
|------|------|------|------|----------|
| 素材设计师 | ADA | 素材创建 | 通过 asset_type 切换模式，处理物品/人物/场景的分析与生图 | Gemini 文本 + Nano Banana |
| 创意总监 | DA | 视频生成 | 需求拆解 + 脚本生成 + 编排 VA/VGA/FFmpeg + 自检审核 | Gemini 文本 |
| 美术指导 | VA | 视频生成 | 链式图生图生成分镜，保持画面一致性 | Nano Banana (img2img) |
| 剪辑师 | VGA | 视频生成 | 首尾帧生成视频片段 | Veo 3.1 |

> **TA（脚本策划）已合入 DA**：DA 既是编排者也是脚本创作者，成为真正的"创意总监"
> **QA（质控）已移除**：DA 通过 self_check 自检替代独立 QA 环节
> **MA（音频师）已移除**：Veo 3+ 自带语音生成（`generate_audio=True`）
> **PDA/CDA/SDA 已合并为 ADA**：三者工作流同构，合并为一个 Agent + 三套 prompt 模板

## 前端布局

### 主页：素材库 + 快速生成

主页分为上下两个区域，一屏展示：

**上半部分 — 素材库（三列并排）**

物品、人物、场景三个类别同时展示为三列，不使用标签页切换。每列包含：
- 列标题 + 素材计数
- "添加"按钮
- 已有素材卡片列表（垂直排列）

用户可在任意一列中添加/删除素材，三列始终同时可见。

**下半部分 — 快速生成区**

1. **文本框**：一句话描述想要的视频（对应模式 B）
2. **三个上传区**（并排）：
   - 物品图片（**必传**，1~3 张）
   - 人物参考图（可选）
   - 场景参考图（可选）
3. **参数配置**：平台选择 + 时长选择
4. **生成按钮**

快速生成流程：用户输入描述 + 上传物品图 → 系统自动创建素材 → 进入视频生成流水线。

### 生成视频页（模式 A）

从素材库选择已有素材组合生成，适合素材已经创建好、需要反复组合的场景。

### 进度页 + 结果页

与现有设计一致：SSE 实时进度 → 视频预览 → 下载。

## 边界说明

### 做什么
- 素材库管理：创建/存储/复用物品、人物、场景
- 快速模式：DA 拆解一句话需求 → ADA 创建素材 → 用户确认
- 手动定制：分别定制物品/人物/场景，ADA 辅助生成视觉方案
- 组合生成：选择素材 → DA 编排全链路自动生成带货视频
- 支持 3 个平台比例（抖音/小红书竖屏、YouTube 横屏）
- 支持 3 种时长（15s / 30s / 60s）

### 不做什么
- 不做视频编辑器（用户不能手动改画面）
- 不做多版本对比（一次生成一个版本）
- 不做字幕烧录（用户自己在平台加）
- 不做 BGM（Veo 生成的视频自带语音，不额外加音乐）
- 不支持大型物品（家具、电器、汽车等需要全身/户外场景的产品）
