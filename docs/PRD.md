# VlogForge 产品需求文档（PRD）

## 一句话描述

用户上传产品信息，AI 自动生成一条真人 vlog 风格的带货短视频。

---

## 用户是谁

小商家、个体卖家、电商运营，想要低成本快速产出带货视频，但不会拍摄剪辑。

---

## 用户体验流程

### 第 1 步：填写产品信息

用户打开网页，看到一个简洁的表单，填 6 项内容：

| 输入项 | 示例 |
|--------|------|
| 产品类型 | 氨基酸洗面奶 |
| 产品参考图 | 上传 1~3 张实物照片 |
| 怎么用的 | 挤出泡沫涂在脸上，打圈按摩 30 秒，清水冲洗 |
| 目标平台 | 抖音（竖屏 9:16） |
| 视频时长 | 30 秒 |
| 核心卖点 | 氨基酸成分，温和不紧绷 |

点击 **「生成视频」** 按钮。

---

### 第 2 步：等待生成（看到实时进度）

页面右侧显示进度，用户能实时看到每个阶段的产出：

```
✅ 脚本生成完成                    ← 几秒钟
   ├── 开场：对镜自拍打招呼
   ├── 分段1：展示产品外包装
   ├── 分段2：挤出泡沫特写
   ├── 分段3：洗脸过程
   ├── 分段4：冲洗后素颜近拍
   └── 结尾：总结推荐

⏳ 分镜图生成中 (4/6)              ← 约 1~2 分钟
   [图1] [图2] [图3] [图4] [?] [?]

⬜ 视频片段生成                     ← 约 3~5 分钟
⬜ 质量检查
⬜ 拼接输出
```

用户可以在等待期间预览已生成的脚本和分镜图。

---

### 第 3 步：预览和下载

生成完成后，页面直接播放最终视频。用户可以：
- **播放预览** — 直接在网页上看效果
- **下载视频** — 点击下载按钮，拿到 MP4 文件，直接发抖音/小红书

---

## 示例：从输入到输出

### 用户输入

```
产品类型：氨基酸洗面奶
参考图：product.jpg（一瓶白色洗面奶）
使用方式：挤出泡沫涂在脸上，打圈按摩，清水冲洗
平台：抖音
时长：30 秒
卖点：氨基酸温和配方，洗完不紧绷
```

### AI 生成的脚本（TA 输出）

```
标题：「洗完脸不紧绷是什么体验？」

风格指南：
  人物 — 20 多岁亚洲女生，短发，穿白色 T 恤
  场景 — 明亮的浴室，白色瓷砖，自然光
  风格 — 写实，暖色调，vlog 手持感

分段 1（开场）：
  旁白："姐妹们！你们洗完脸有没有那种紧绷到笑不出来的感觉？"
  画面：女生对着镜头说话，表情夸张
  首帧提示词："年轻亚洲女生，短发白T恤，浴室里对镜头说话，自然光，vlog风格"
  尾帧提示词："同一女生，举起一瓶白色洗面奶展示给镜头"
  需要产品：是 ← VA 会把用户上传的产品图融入画面

分段 2（展示产品）：
  旁白："这款氨基酸洗面奶，成分超温和"
  画面：手持产品特写，翻转展示
  首帧提示词：（= 上一段的尾帧）
  尾帧提示词："女生把洗面奶挤在手心，白色泡沫，特写"
  需要产品：是

分段 3（使用过程）：
  旁白："泡沫很绵密，上脸打圈完全不刺激"
  画面：涂泡沫在脸上打圈
  首帧提示词：（= 上一段的尾帧）
  尾帧提示词："女生在水龙头下冲洗脸部"
  需要产品：否

分段 4（效果展示）：
  旁白："你看，洗完完全不紧绷，皮肤滑滑的"
  画面：擦干脸，近距离展示皮肤状态
  首帧提示词：（= 上一段的尾帧）
  尾帧提示词："女生对镜头比心微笑"
  需要产品：否

分段 5（收尾）：
  旁白："真的推荐你们试试，链接放评论区了！"
  画面：对镜头比心 + 产品摆拍
  首帧提示词：（= 上一段的尾帧）
  尾帧提示词："产品放在洗手台上，旁边有毛巾和绿植，氛围感摆拍"
  需要产品：是
```

### 分镜图链条（VA 输出）

```
帧1        帧2        帧3        帧4        帧5        帧6
对镜说话 → 举起产品 → 挤泡沫 → 冲洗 → 比心微笑 → 产品摆拍
  │          │          │        │         │          │
  └── 视频1 ─┘          │        │         │          │
             └── 视频2 ─┘        │         │          │
                        └─ 视频3 ┘         │          │
                                 └─ 视频4 ─┘          │
                                           └── 视频5 ─┘
```

每个视频片段约 6 秒，5 段 = 30 秒。

### 最终输出

一个 30 秒的 MP4 视频文件，竖屏 9:16，带真人画面 + 语音旁白，可以直接发到抖音。

## 幕后：Agent 分工

用户看不到这些，但系统内部是这样工作的：

```
用户 → DA（创意总监）
         │
         ├→ TA（脚本策划）：写脚本 + 分镜提示词
         │
         ├→ VA（美术指导）：用 Nano Banana 生成分镜图
         │    └ 产品帧会把用户上传的照片融入画面
         │
         ├→ VGA（剪辑师）：用 Veo 3.1 把相邻分镜图变成视频
         │    └ 首尾帧功能：帧A→帧B 生成一段带语音的视频
         │
         ├→ QA（质控）：检查每段视频有没有画面瑕疵
         │
         └→ FFmpeg 拼接：裁掉重复帧，串成完整视频
```

## 边界说明

### 做什么
- 根据用户输入自动生成完整带货视频
- 支持 3 个平台比例（抖音/小红书竖屏、YouTube 横屏）
- 支持 3 种时长（15s / 30s / 60s）
- 产品参考图自然植入画面

### 不做什么
- 不做视频编辑器（用户不能手动改画面）
- 不做多版本对比（一次生成一个版本）
- 不做字幕烧录（用户自己在平台加）
- 不做 BGM（Veo 生成的视频自带语音，不额外加音乐）
