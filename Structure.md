# 创意总监 + Sub-Agent 架构说明

## 整体结构

- **对用户**：内容侧只有一个入口 —— **创意总监（DA）**，负责编排与输出
- **对系统**：存在两个**平行部门**——**创意侧**（创意总监 + 其下属 Sub-Agent）与 **HR**；HR 与创意总监平级，可管理**所有 Agent**（含 DA 与所有 Sub-Agent）的提示词
- **输出**：由创意总监汇总、排序后，以**一条连贯的多模态流**（文字 + 图片 + 音频 / 视频）呈现给用户

---

## 角色列表

### 一级：平行部门

| 部门/角色          | 对应名称            | 职责                                                                                   | 说明                                                                |
| ------------------ | ------------------- | -------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| **创意总监** | DA (Decision Agent) | 接收用户需求 → 拆解任务 → 调度 Sub-Agent → 汇总结果 → 以一条 interleaved 流输出    | 创意侧唯一对用户的**内容出口**                                |
| **HR**       | HR (HR Agent)       | 管理**所有 Agent**（DA + TA / VA / VGA / MA / QA）的提示词（prompt），优化其表现 | 与创意总监**平行的部门**，不参与内容生产，只负责「训练/调参」 |

---

### Sub-Agent（创意总监下属，按职能）

| 角色               | 对应名称               | 职责简述                                       | 产出形态            |
| ------------------ | ---------------------- | ---------------------------------------------- | ------------------- |
| **脚本策划** | TA (Text Agent)        | 故事结构、大纲、分镜脚本、对白与旁白文案       | 文本                |
| **美术指导** | VA (Visual Agent)      | 根据脚本/分镜生成插画、画面、视觉素材          | 图像                |
| **剪辑师**   | VGA (Video Gen Agent)  | 根据分镜与素材生成或编排视频片段               | 视频                |
| **音频师**   | MA (Music/Audio Agent) | 背景音乐、音效、旁白/配音                      | 音频                |
| **质控**     | QA (Review Agent)      | 校验风格一致、逻辑连贯、质量达标，提出修正建议 | 审核结果 / 修正建议 |

## 协作关系（示意）

```
         ┌─────────────────────────────────────────────────────────────┐
         │                      平行部门                                  │
         └─────────────────────────────────────────────────────────────┘
                    │                                    │
        ┌───────────┴───────────┐             ┌──────────┴──────────┐
        │    创意侧（内容生产）   │             │   HR（提示词管理）    │  ← 与创意侧平行，管理所有 Agent 的 prompt
        └───────────┬───────────┘             └──────────┬──────────┘
                    │                                    │
                    │                                    │ 调优 / 更新 prompt
                    ▼                                    ▼
                  用户                    ┌──────────────┴──────────────┐
                    │                    │  可管理：DA + TA + VA + VGA + MA + QA  │
                    ▼                    └─────────────────────────────┘
        ┌───────────────────────────────────────────────────┐
        │                    创意总监（DA）                    │  ← 唯一对用户的内容出口，输出一条多模态流
        │        理解需求、拆任务、编排、汇总、流式输出          │
        └───────────────────────────────────────────────────┘
                            │
        ┌───────────────────┼───────────────────┐
        │                   │                   │
        ▼                   ▼                   ▼
     TA(文本)             VA(视觉)            VGA(视频)
        │                   │                   │
        └───────────────────┼───────────────────┘
                            │
                    ┌───────┴───────┐
                    ▼               ▼
               MA(音乐/音效)      QA(审核)
```

---

## 说明

- **创意总监（DA）**：负责日常内容生产与对用户的一条流输出，需保证符合赛题对 Gemini interleaved/mixed output 的使用要求。
- **HR**：与创意总监所在创意侧**平行的部门**，可管理**所有 Agent**（含 DA 与 TA / VA / VGA / MA / QA）的 system prompt / 提示词，不参与内容生产、不直接响应用户内容请求。
- Sub-Agent 的调用顺序、是否全部参与一次任务，由创意总监在实现中决定；后续若增删角色，可在此文档同步更新上表与示意图。
